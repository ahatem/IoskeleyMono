# Ioskeley Mono

Proposed opening copy for the production README. Package guidance describes the existing distributions; this page does not announce an Ioskeley 3 release.

**An open programming typeface built on Iosevka.**
Compact, geometric, and tuned for editors, terminals, technical interfaces, and the web.

> Distinctive when inspected. Quiet when used.

Ioskeley began as an experiment inspired by Berkeley Mono's compact technical character. It grew into an independent open font project with its own width system, terminal builds, no-ligature family, Nerd Font packages, web distributions and design decisions.

Berkeley Mono remains part of the project's heritage, not its specification. Ioskeley is independently generated from Iosevka and may intentionally diverge when readability, coverage, terminal correctness or its own identity benefits.
