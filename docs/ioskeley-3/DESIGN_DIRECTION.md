# Ioskeley 3 — Design & Product Direction

## Design goal
**Technical character without visual noise. Compact without feeling crushed. Distinctive when inspected; quiet when used.**

Ioskeley began as an Iosevka experiment inspired by Berkeley Mono. Berkeley remains design heritage and a useful calibration reference, not the specification.

## Priority order
1. Correct monospace/terminal behavior
2. Readability and ambiguity resistance
3. Stable rhythm across weights/styles
4. Ioskeley identity
5. Berkeley-inspired fidelity
6. Additional packages

## Principles
- Useful density, not maximum compression.
- Clear glyph differentiation.
- Long-session calm.
- Validate compiled measurements against specimens from everyday use.
- Broad Iosevka coverage is an asset.
- Existing variants need demonstrated use cases.
- New variants must earn permanent maintenance cost.
- Attribution is explicit: Iosevka/Belleve Invis as foundation; Berkeley Mono/Neil Panchal as inspiration; no affiliation or copied Berkeley outlines.
