03 — Families & builds

Three builds, two widths

Every family carries ten weights in upright and italic. The difference between them is ligatures and terminal rhythm — nothing else.

Standard

Ioskeley Mono

The everyday choice. Programming ligatures are on, and the full glyph repertoire is present.

Editors, IDEs, anything that shows ligatures well.

Term

Ioskeley Mono Term

Arrow and box-drawing forms are tuned for a terminal grid, so they keep their rhythm at cell size.

Terminals: Kitty, Ghostty, WezTerm, Alacritty.

NL

Ioskeley Mono NL

No programming ligatures at all. Ordinary character shaping only.

Apps that cannot disable ligatures, or where you want none.

Widths

Normal 600 · SemiCondensed 540

Two widths in every package. SemiCondensed is 90% of Normal, so it fits 90% of the characters in the same space.

04 — Nerd Font geometry

NF or NFM?

Each Nerd Font archive ships two patched variants. They carry the same icons and differ only in geometry — pick the one your application expects.

NF — Nerd Font

Ioskeley Mono Nerd Font

Ordinary Nerd Font geometry, with the larger icons kept intact. An icon may extend a little past one cell — that is normal, and looks right in most prompts.

A good default when you simply want icons.

NFM — Nerd Font Mono

Ioskeley Mono Nerd Font Mono

Strict single-cell geometry. Every glyph, icon included, stays inside one cell with no overhang, which is what Fontconfig and some font pickers require of a true monospace face.

For tools that demand strict cell geometry.

Applies to 2.2.0. The currently published v2.1.0 archives do not contain this split, and ship neither variant. If you are on v2.1.0, ignore this section until 2.2.0 is released. The download links below point at the latest published release, so they serve v2.1.0 today and will resolve to the 2.2.0 archives automatically once it is out.

06 — Width

Normal and SemiCondensed

The same text at the same size in both widths. SemiCondensed keeps the design and tightens the spacing to 540 units per character.

Both widths ship inside every desktop and Nerd Font archive. There is no third, narrower width.

08 — Origins

Origins & design evolution

Berkeley Mono / TX-02 inspired the first experiment, and Iosevka made it possible to run. Both are history rather than specification: a hundred-odd builds and repeated tuning moved Ioskeley toward a design of its own. The studies below are kept as a record of that process. They are comparison plates, deliberately monochrome, and they are not a claim of equivalence.

10 — Install & use

Getting it running

Manually

Unzip an archive, choose Normal or SemiCondensed, then Hinted for standard-DPI Windows and Linux displays or Unhinted for macOS and HiDPI.

Windows: right-click → Install. macOS: open in Font Book. Linux: copy to ~/.local/share/fonts/IoskeleyMono/ and run fc-cache -fv.

Editors

Use the family name that matches what you installed.

// VS Code — settings.json
{
  "editor.fontFamily": "'Ioskeley Mono', monospace",
  "editor.fontLigatures": true,
  "editor.fontWeight": "400",
  "editor.fontSize": 14.5
}

Terminals

The Term family keeps terminal forms on the grid.

# Ghostty — config
font-family = Ioskeley Mono Term
font-size   = 14

# Kitty — kitty.conf
font_family Ioskeley Mono Term
font_size   14.0

On the web

IoskeleyMono-Web.zip is a compact WOFF2 subset; IoskeleyMono-Web-Full.zip adds Greek, Cyrillic and the wider symbol range. Both use the same filenames.

@font-face {
  font-family: "Ioskeley Mono";
  src: url("./IoskeleyMono-Regular.woff2")
       format("woff2");
  font-weight: 400;
  font-display: swap;
}
