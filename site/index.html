Why it exists

Made from the font I kept searching for

For a long time, Berkeley Mono was the font I dreamed of using. I loved its compact proportions and the character it gave to code, but I could not afford it at the time. I kept looking for a free typeface that could give me a similar feeling.

When I found Iosevka, I realized I could shape something of my own. More than a hundred builds followed, with a lot of installing, uninstalling, zooming, comparing, and testing in real editors until the details felt right.

Ioskeley Mono is the result. It is an independent Iosevka-based typeface, shared freely for students, people starting their careers, and anyone who wants a distinctive coding font without a high price standing in the way.

Build from Source

  
Tagged releases are built automatically. To reproduce the current source build locally:

  

    

      Prerequisites: Node.js 20, npm, Git
    

    
# 1. Clone the repository and the pinned Iosevka source
git clone https://github.com/ahatem/IoskeleyMono.git
git clone --depth 1 --branch v34.4.0 https://github.com/be5invis/Iosevka.git

# 2. Copy the customized build plan
cp IoskeleyMono/private-build-plans.toml Iosevka/

# 3. Install build tools and compile fonts
cd Iosevka
npm install
npm run build -- contents::IoskeleyMono contents::IoskeleyMonoTerm contents::IoskeleyMonoNL contents::IoskeleyMonoWeb

    

      Output: Iosevka/dist/<PlanName>/. The release workflow creates hinted, Nerd Font, and packaged variants.
